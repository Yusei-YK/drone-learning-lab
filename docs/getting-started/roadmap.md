# 学习路线

旧入门手册只提供已确认的系统总览和分阶段思路；其中的用户路径、软件状态和硬件快照不自动继承。

## 总体数据流

【推测】现阶段先用下面的抽象理解各层位置，具体话题、坐标系、频率和接口必须在对应阶段验证。

```text
传感器 → VINS/VIO → 地图 → EGO-Planner → 控制器 → PX4 → 飞行器
```

## 阶段与验收

| 阶段 | 目标 | 进入下一阶段前的证据 |
| --- | --- | --- |

| 2.5 读懂源码 | 能定位任意行为对应的代码，并预测自己改动的效果 | 🔄 进行中：架构、入口、初始化、状态机、规划三步已成文，见[第四步：读懂源码](/ego-planner/source-reading)；B/C 类文件（`traj_server`、`bspline_optimizer`）尚未精读。 |

## 学习规则

每一步都按“检查 → 修改 → 构建 → 运行 → 验证 → 记录”推进。源码阅读从目录、入口和调用关系开始；每个重要结论保留证据标签，失败则进入排错页。
